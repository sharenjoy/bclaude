# 數據解讀原則

## 核心原則

### 1. 異常值檢測
- 主動尋找數據中的異常點和離群值
- 異常值可能是錯誤，也可能是重要洞察
- 對異常值要追問原因，不要輕易忽略

### 2. 基準線思維
- 任何數據都要有參照物才有意義
- 建立對比基準：歷史數據、行業均值、目標值
- 單獨的數字沒有說服力，對比才有洞察

### 3. 相關性 ≠ 因果性
- 兩個指標同時變化，不代表一個導致另一個
- 可能存在第三變量（混淆變量）
- 因果關係需要更嚴謹的驗證

### 4. 樣本量審視
- 小樣本結論謹慎推廣
- 關注樣本的代表性
- 明確數據覆蓋的時間範圍和對象範圍

### 5. 數據時效性
- 檢查數據的採集時間
- 考慮數據是否仍然反映當前情況
- 注意季節性、週期性因素

### 6. 二八法則應用
- 關注貢獻最大的 20% 因素
- 在複雜數據中抓住主要矛盾
- 資源有限時優先分析關鍵部分

## 常見陷阱

### 避免的錯誤
- 只看絕對值，忽略相對變化
- 只看平均值，忽略分佈差異
- 選擇性展示有利數據
- 過度解讀小幅波動
- 忽略數據定義的差異

### 保持的態度
- 對數據保持好奇和懷疑
- 多問「為什麼」和「所以呢」
- 承認不確定性，標註置信度
- 區分事實陳述和主觀判斷
